# 📊 Módulo de Contabilidad

Este repositorio contiene el desarrollo de un **módulo de contabilidad digital**, diseñado para integrarse en sistemas de gestión empresarial. El objetivo principal es facilitar el registro, control y análisis de operaciones contables.

## 👥 Equipo de desarrollo

- **Ethan** — Especialista en interfaz de usuario y ayuda con base de datos
- **Araceli** — Encargado de la lógica de negocio y conexión con la base de datos 
- **Felipe** —  Encargado de la lógica y conexión con la base de datos junto Araceli

## 🔍 Funcionalidades principales

- Generación de reportes contables
- Gestión de cuentas y categorías contables
- Exportación de datos a formatos CSV y PDF
- Filtros por fechas, cuentas y tipo de operación

## 🛠️ Tecnologías utilizadas

- **Frontend:** Angular 
- **Backend:** Django
- **Base de Datos:** MySQL
